## 本機開發

需求：Node.js 20+

```bash
npm install
cp .env.example .env.local   # 填入必要設定值
npm run dev                   # http://localhost:3000
```

其他指令：

```bash
npm run build       # 正式建置
npm run typecheck   # 型別檢查
npm run lint        # Lint
```
